`MedCPT` `BM25` `Weaviate` `DeepSeek-V3` `PubMedQA`

### [LinkedIn Profile NLP Classifier](https://github.com/AswiniS94/LinkedIN_Profile_Classification_using_NLP)
Classifying professional profiles using natural language processing. Feature extraction from unstructured text with transformer-based and classical ML models.
`NLP` `DistilBERT` `Python` `Scikit-learn`
